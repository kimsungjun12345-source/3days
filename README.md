# 작심삼일 🔥

> 「작심삼일도 여러 번 하면 평생이 된다」

**딱 3일만 약속하는 자기계발 앱**입니다.

마음을 먹고 뭔가를 시작해도 포기할 수 있습니다. 그래도 괜찮습니다.
그때가 되면 **또다시 작심삼일**을 하면 되니까요.
3일이 모여 6일이 되고, 9일이 되고, 반복하다 보면 평생이 됩니다.

## 컨셉

- **약속은 딱 3일** — 거창한 목표 대신 3일짜리 사이클로 부담을 낮춥니다.
- **3일 완주하면 또 작심** — "또 작심하기" 버튼으로 다음 3일을 이어갑니다. 완주 횟수 × 3일이 쌓입니다.
- **무너져도 실패가 아님** — 하루를 건너뛰면 사이클만 새로 시작할 뿐, 지금까지 쌓은 날들은 그대로 남습니다. 오히려 '다시 일어난 횟수'를 훈장처럼 보여줍니다.

## 실행 방법

빌드나 설치가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

```bash
# 로컬 서버로 열고 싶다면
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages에 그대로 배포할 수도 있습니다 (Settings → Pages → 브랜치 선택).

## 기술

- 순수 HTML / CSS / JavaScript — 프레임워크·빌드 도구 없음
- 데이터는 브라우저 `localStorage`에 저장 (서버·계정 불필요)
- 모바일 우선 반응형 UI

## 동작 규칙

| 상태 | 조건 | 다음 행동 |
|------|------|-----------|
| 진행 중 | 이번 사이클 체크 0~2개, 어제까지 이어짐 | "오늘 해냈어요" 체크 (하루 1회) |
| 완주 | 3일 모두 체크 | "또 작심하기"로 다음 3일 시작 |
| 잠깐 멈춤 | 하루 이상 건너뜀 | "다시 작심삼일"로 오늘부터 재시작 (누적 기록 유지) |
