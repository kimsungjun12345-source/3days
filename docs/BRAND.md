# 셋돌하나의 그림 — 돌 · 워드마크 · 아이콘

이 문서는 취향을 적는 자리가 아니라 **시안이 코드에 들어맞게 하는 치수표**다.
그림이 예쁜지는 눈으로 정하고, 여기 적힌 값은 재서 정한다.

셋이 한 벌이어야 하는 이유는 이 앱의 규칙이 `3일 → 돌 하나 → 다시 쌓기`
하나뿐이기 때문이다. 돌이 브랜드의 가장 고유한 시각 언어이므로 **돌을 먼저
정하고, 그 둥근 정도를 보고 워드마크를, 마지막에 아이콘을** 만든다.

## 그림체

**Soft Pebble Garden** — 정원에서 하나씩 주워 모은 조약돌.

- 낮은 채도 · 둥글고 약간 비정형 · 손으로 만진 듯한 형태
- 그림자 최소 · 3D가 아니라 2.5D
- 하지 않는 것: 광택 3D · 과한 그라데이션 · **얼굴 달린 돌** · 반듯한 SaaS 로고

귀여움은 형태와 움직임이 만든다. 돌이 살짝 기울고, 툭 놓이고, 작게
흔들렸다 멈추는 것으로 충분하다. 얼굴을 붙이는 순간 이 앱은 캐릭터 습관
앱이 되고, 잡아 둔 방향(차분함 · 회복 · 작은 성취)에서 벗어난다.

## 돌 — 여기가 70%다

### 실루엣 세 종의 조건

`pebble-a.svg` · `pebble-b.svg` · `pebble-c.svg`.

**셋의 발자국(bounding box)이 같아야 한다.** 이것이 이 문서에서 가장
중요한 한 줄이다.

돌마다 실루엣을 달리하는 것은 이 저장소에서 **두 번 시도해 두 번 물린**
방향이다. 한 번은 3일마다 모양을 고르게 하던 `goal.stoneShapes`였고, 한 번은
조약돌 윤곽(점 열 개를 씨앗값으로 민 닫힌 곡선)이었다. 두 번째 주석이
남아 있다 — *"가까이 보면 손으로 주운 돌 같았지만, 여러 채가 서면 울퉁불퉁한
덩어리로 뭉쳐 보였다."*

원인은 아이디어가 아니라 진폭이었다. 폭과 높이가 층마다 달라지면 탑 윤곽이
지그재그가 되고, 그러면 정돈된 정원이 아니라 부스러기 더미로 읽힌다.
그러니 셋은 **가로·세로를 같게 두고 가장자리 성격만** 다르게 한다 — 한쪽이
살짝 눌린 정도, 곡률이 꺾이는 자리, 좌우 비대칭. 그 정도면 반복이 눈에
띄지 않으면서 탑은 단정하다.

### SVG 형식

```
viewBox="0 0 100 100"      셋 다 동일. 돌이 차지하는 영역도 셋 다 동일
<g class="pebble-top">     윗면 — 넓고 부드러운 비정형 곡선
<g class="pebble-side">    옆면 — 아주 얕게
```

- **fill을 넣지 않는다.** 작심마다 다른 색을 코드가 입힌다. 색이 박혀
  있으면 6색이 하나도 안 먹는다
- **옆면을 어둡게 하는 것도 코드가 한다.** 그래야 6색 × 2테마 = 12벌을
  SVG 12개로 만들지 않아도 된다
- **그림자를 SVG에 넣지 않는다.** 홈·정원·공유 카드·아이콘이 각각 다른
  거리에서 보므로 상황별로 코드가 건다
- 하이라이트는 없어도 되고, 있어도 한쪽에 아주 미세하게

### 색 — 여섯 벌이 필요하다

작심 자리는 **6개**다(`GOAL_LANES`가 여섯 — 정원에 줄이 여섯이라 그 이상은
설 자리가 없다). 다섯만 정하면 여섯 번째 작심이 색을 재사용한다.

그리고 **밝은 화면용과 어두운 화면용을 따로** 정한다. 같은 값을 그대로 쓰면
어두운 배경에서 밝은 돌이 떠 보인다 — 예전에 그래서 갈라놓았다.

기준선(밝은 화면):

| | 값 |
|---|---|
| Warm Stone | `#C9B9A3` |
| Sage Stone | `#A9B4A0` |
| Dusty Blue Stone | `#A9B9C4` |
| Clay Stone | `#C89D8A` |
| Cool Gray Stone | `#B5B4B0` |
| (여섯째) | **미정** |

옆면은 각 색보다 10~15% 어둡게 — 코드가 계산한다.

이 팔레트는 앞선 결정을 뒤집는 것이다. 지금 코드는 *"색을 세게 주면 정원이
아니라 색깔 범례가 된다"*고 적어 두고 채도를 거의 0으로 두었다. 위 값들은
충분히 탁해서 괜찮아 보이지만 **여섯이 한 화면에 섰을 때** 확인하고 넘어간다.
색깔 보석 수집처럼 보이면 물린 것이다.

### 시안은 작게 놓고 판단한다

정원에서 탑 하나는 **40~60px**이다. 1024px에서 아름다운 조약돌이 거기서는
회색 알약이 된다. 아이콘을 48px 옆에 놓고 그리듯, 돌도 축소본을 옆에 놓고
그린다.

## 워드마크 — 30%

기존 폰트를 그대로 쓰기보다 둥근 한글을 조금 손본다. 획 끝이 둥글고, 너무
두껍지 않고, 글자 폭이 넉넉하고, `ㅅ`·`ㄷ`·`ㅎ`의 각진 데를 살짝 부드럽게.
완벽하게 균일하지 않은 2~3%의 손맛. 전체는 한 줄.

강조는 `하나`에만, 그것도 아주 미묘하게. `셋돌 하나!!`처럼 보이면 안 된다.

### 색

| | 값 | 비고 |
|---|---|---|
| 기본 | `#3F3B36` | 밝은 배경에서 9.93:1 — 넉넉하다 |
| 강조 | **미정** | 아래 참고 |

강조색으로 제안된 `#7F967A`는 밝은 배경 `#f7f6f3` 위에서 **2.87:1**이다.
큰 글자 기준(3:1)도 못 넘긴다. `#6B8465` 정도면 3.6:1이 나온다.

**이 값을 미리 맞춰야 하는 이유가 따로 있다.** 워드마크가 글자일 때는
`test/contrast.js`가 밝은/어두운 4조합을 자동으로 재 준다. SVG 이미지가 되는
순간 그 그물에서 빠진다 — 자동으로 잡히지 않으니 사람이 재서 넣어야 한다.

### sage는 이미 임자가 있다

`--sage`는 다시 쌓음 · 복귀 시트 · "N번 다시 쌓는 중" · 쉬는 중 상태줄이
쓰는 색이다. 워드마크가 같은 색을 쓰면 브랜드와 회복이 색으로 묶이는
이점이 있고, 대신 회복 신호가 흔해져 힘이 빠질 위험이 있다.

어느 쪽으로 가든 **값은 한 벌로 합친다.** 지금 셋이 될 판이다 —
밝은 `#5f7d54`, 어두운 `#86a578`, 워드마크 `#7F967A`.

### SVG 형식

```
wordmark.svg          한 개
viewBox만 유지          width/height 하드코딩 제거
배경 없음
<g class="wordmark-main">     fill="currentColor" — 테마마다 CSS가 색을 준다
<g class="wordmark-accent">   강조만 별도 그룹
```

글자는 **Flatten으로 path 변환**한다(`Outline Stroke`는 stroke를 path로
바꾸는 기능이라 텍스트 벡터화에는 맞지 않는다). `<text>`가 남아 있으면
폰트 없는 기기에서 엉뚱하게 렌더된다.

이미지가 되어도 **읽어 주는 이름은 남긴다** — 앱바의 `<h1>`은 스크린리더가
읽을 글자를 그대로 갖고 있어야 한다.

## 아이콘

앱 안의 돌탑을 그대로 축소하지 않는다. 48px에서 한눈에 보여야 한다.

**A안 — 큰 조약돌 세 개.** 3일 · 쌓는다 · 돌을 한꺼번에 가져간다.
아이콘은 브랜드 상징이지 인앱 메커니즘의 설명이 아니므로, 앱 아이콘은
돌 셋이고 앱 안의 보상은 돌 하나여도 어긋나지 않는다.

1024×1024 마스터 하나만 만든다. 나머지 크기는 `scripts/make-native-assets.js`가
만든다.

### 놓치기 쉬운 두 가지

- **안드로이드 어댑티브 아이콘은 바깥 33%가 잘린다.** 심볼을 가운데
  **66% 원 안**에 둔다. 지금 스크립트는 inset 10%인데, 그 값까지 꽉 채우면
  둥근 마스크에서 돌 끝이 날아간다
- **iOS 앱스토어 아이콘은 투명과 둥근 모서리가 금지**다. 배경을 꽉 채운
  정사각형으로 만든다 — 모서리는 애플이 씌운다

## 바뀌면 함께 바뀌는 것

돌 모양은 **세 군데에 따로 구현되어 있다.** 하나만 고치면 나머지 둘이
조용히 어긋난다.

| | 무엇 |
|---|---|
| `app.js` `stonePiece()` | 앱 화면의 돌 (SVG, 층마다 계산해서 그린다) |
| `scripts/make-native-assets.js` | 앱 아이콘 · 스플래시 |
| `share.js` `drawTower()` | 공유 카드 (SVG가 아니라 Canvas다) |

그리고 다시 뽑아야 하는 것들 — 전부 스크립트가 만든다.

```bash
node scripts/make-native-assets.js   # 아이콘 · 스플래시 (안드로이드/iOS 전 크기)
node scripts/make-store-shots.js     # 스토어 스크린샷 15장
node scripts/make-feature-graphic.js # 피처 그래픽 1024×500
npm test                             # 명암비 포함
```
