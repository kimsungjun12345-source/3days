# 스토어 등록 문구

그대로 복사해 쓸 수 있게 정리했습니다. 핵심은 하나입니다 —
**이 앱은 습관을 지키게 하는 앱이 아니라, 못 지킨 다음에 돌아오게 하는 앱입니다.**
모든 문구가 그 한 가지를 말합니다.

---

## 앱 이름

```
작심삼일
```

부제(App Store, 30자 이내):

```
딱 3일만 약속하는 습관 앱
```

짧은 설명(Play, 80자 이내):

```
약속은 딱 3일. 무너져도 괜찮아요, 다시 쌓으면 되니까. 3일마다 나의 돌탑이 자랍니다.
```

---

## 전체 설명

```
「작심삼일」은 3일 만에 포기하는 앱이 아니라, 3일씩 해내는 앱입니다.

습관 앱을 깔았다가 지워본 적 있나요?
하루 빠뜨린 순간 연속 기록이 0으로 돌아가고,
그날로 앱을 열지 않게 되죠.

작심삼일은 그 반대편에 있습니다.
약속은 딱 3일. 3일을 채우면 돌 하나가 쌓이고,
무너지면 다시 쌓으면 됩니다.
돌탑은 원래 무너지면 다시 쌓는 것이니까요.


▶ 약속은 딱 3일

거창한 목표 대신 사흘만 약속합니다.
"아침에 물 한 잔", "10분 걷기" 같은 작은 것으로 충분해요.
3일이면 누구나 해볼 만하니까요.


▶ 3일을 채우면 돌 하나

작심삼일을 완주할 때마다 나의 돌탑에 돌이 하나씩 얹힙니다.
작심 하나가 탑 하나. 홈 화면에는 그 탑들이 모인
나만의 돌탑 정원이 자랍니다.

작심삼일 120번이면 1년입니다. 진짜로요.


▶ 무너져도 사라지지 않아요

하루를 건너뛰어도 쌓아 둔 돌은 그대로 남습니다.
"실패"라고 부르지 않고, 며칠 쉬었는지만 조용히 알려드려요.
그리고 돌아오면 이렇게 인사합니다.

"돌아왔네요. 그거면 충분해요."


▶ 다시 쌓은 횟수가 진짜 기록

이 앱은 '며칠 연속'을 자랑하지 않습니다.
대신 '몇 번 다시 왔는가'를 셉니다.
무너지고도 돌아온 사람이 결국 탑을 완성하니까요.

지난 12주의 기록을 보면 빈칸도 보입니다.
그 빈칸도 이야기의 일부입니다.


▶ 조용한 알림

저녁 9시에 한 번, 오늘 남은 돌이 있을 때만 알려드립니다.
쉬고 있을 때는 재촉하는 대신 이렇게 말합니다.
"쌓아 둔 돌 N개는 그대로예요."


▶ 기록은 내 기기에만

계정도, 로그인도 없습니다.
모든 기록은 기기 안에만 저장되고 어디로도 전송되지 않습니다.
필요하면 파일로 내보내 두었다가 언제든 되살릴 수 있어요.


작심삼일도 여러 번 하면, 평생이 됩니다.
```

## 키워드 (App Store, 100자 이내, 쉼표 구분)

```
습관,루틴,작심삼일,3일,목표,자기계발,체크리스트,habit,다짐,기록,동기부여,미라클모닝,갓생,플래너
```

'습관 트래커' 같은 레드오션 키워드보다 **작심삼일**이 핵심입니다.
검색량은 있는데 경쟁이 없는 브랜드 키워드이고, 앱 이름 자체가 ASO 자산입니다.

## 심사 메모 (App Review Notes)

```
로그인이나 계정이 필요 없는 앱입니다. 모든 기록은 기기 내부(localStorage)에만
저장되며 서버로 전송하지 않습니다.

알림은 서버 푸시가 아니라 기기 안에서 예약하는 로컬 알림입니다.
사용자가 설정 화면의 토글을 켤 때에만 권한을 요청하며, 끄면 예약된 알림이
모두 취소됩니다.

앱 실행 후 '새 작심 만들기'로 목표를 추가하고 '오늘의 돌 얹기'를 누르면
핵심 기능을 바로 확인하실 수 있습니다.
```
